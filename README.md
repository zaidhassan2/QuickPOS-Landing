# QuickPOS Landing Page

Welcome to the QuickPOS project repository. This is a modern, responsive landing page designed for a Point of Sale (POS) SaaS platform. It was built using an Agile workflow (Scrum) via Jira and version control via GitHub.

## 🚀 Features
* **Modern UI/UX:** Clean, responsive design using modern CSS features (Flexbox, CSS Grid).
* **Responsive Layout:** Fully optimized for mobile, tablet, and desktop viewing.
* **Pricing Tier:** A three-tier pricing structure (Basic, Pro, Enterprise) with visual hierarchy.
* **Functional Contact Form:** A server-side validated PHP contact form with success redirection.

## 🛠️ Technologies Used
* **Frontend:** HTML5, CSS3
* **Backend:** PHP 8+
* **Project Management:** Jira (Scrum methodology)
* **Version Control:** Git & GitHub
* **CI/CD Integration:** Slack Bots (GitHub & Jira tracking)
